Indonesia in Numbers — a working national statistics site for Indonesia, with real figures from BPS, UN World Population Prospects 2024, and World Bank WDI, each shown with its source and year. Static files with no network requests, desktop and phone layouts, and working charts, filters, search, and province comparison.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To build the hand-in output instead: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
